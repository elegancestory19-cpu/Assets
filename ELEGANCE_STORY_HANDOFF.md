## 5. Technical notes for the assistant
- **Arabic rendering:** Pillow + libraqm with Cairo ExtraBold (google/fonts) works. Numbers and the email must be isolated LTR runs inside RTL layouts.
- **lemo-opuscar skill** (github.com/lemomo-ai/lemo-opuscar, MIT): install it with `claude plugin marketplace add lemomo-ai/lemo-opuscar` then `claude plugin install lemo-opuscar@lemolab`.
  - Real instruments: `sh tools/fetch.sh instruments karoryfer|vcsl|freepats`, then `core/audio/sampler.py`.
  - Render: `node core/render/video.mjs <project> --fps 24 --size 1080x1920`.
  - The skill wants ffmpeg 7+. With ffmpeg 6, mux and loudnorm yourself.
- **Speech check:** a Whisper model from sherpa-onnx (GitHub releases) worked when HuggingFace was blocked.
- **Brand palette (sampled from the logo):** cyan #1CCEE9, blue #2457D6, purple #8844C0, magenta #DA43AE, orange #E57E22, yellow #F7C947, stage #070707. Microgame home palette: violet #2a0f5c, magenta #ff2e88, gold #ffc928, cyan #1fd1d1.
